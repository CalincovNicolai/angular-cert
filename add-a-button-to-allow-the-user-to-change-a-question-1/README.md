# Add a button to allow the user to change a question


# Challenge Description

In this challenge, We want to display an additional button in the quiz to allow the user to swap a question with a new one.

## Requirements

- Add a new button "Change question" next to the 4 possible answers to each question.
- When the user clicks on any of these buttons, remove the selected question and replace it with another one generated from the API.
- Only one question can be swapped per quiz, which means once the user clicks on any of these buttons, remove all  “Change question” buttons.
- Creating a new quiz resets the ability to change a question.

## Other Considerations

- If you see the `data-test` attribute anywhere in the boilerplate don't remove it.
